App Description

This application is a simple CRUD (Create, Read, Update, Delete) system built using Ionic Angular and Firebase Firestore. It was developed as part of our laboratory activity.

How to Use Add Product: Add a product with its price, category, and quantity. Products: Search and filter products, update their details, or delete them.

Developed using Ionic & Firebase
